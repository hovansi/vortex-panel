# Vortex MC — đối chiếu panel và phạm vi tính năng

Đợt 0.6.0 chuyển nghiên cứu thành workflow Worlds riêng từng server, SHA-256/CRC và nguồn checksum cho backup, protection ngoài retention, quyền archive manage-only và nhật ký ID chính xác. So sánh nguồn hiện hành Aternos/Pterodactyl/Crafty/Pelican/AMP cùng các ưu tiên chưa triển khai nằm ở [RESEARCH-2026-10-14](RESEARCH-2026-10-14.md); API và giới hạn mới ở [WORLDS](WORLDS.md). Bảng 0.4.1 bên dưới giữ nguyên như lịch sử, không phải bảng quyền hiện tại của 0.6.0.

Nghiên cứu nền ngày **12/10/2026**, bổ sung file workflow và nghiệm thu VPS **0.4.1** ngày **14/10/2026 tại Bangkok**. Nguồn đối thủ giữ đúng ngày nghiên cứu; bảng hiện trạng Vortex được cập nhật theo bằng chứng mới. ## Ưu tiên thiết kế của đợt nâng cấp nền

1. **RBAC xuyên suốt.** Admin, operator, viewer và scope server là nền tảng tối thiểu. Endpoint tải file/backup, schedule, activity, dashboard và WebSocket đều cần kiểm tra cùng policy; đổi role/disable tài khoản phải có tác dụng ngay. Không triển khai riêng UI ẩn nút rồi gọi đó là phân quyền.
2. **Tác vụ có trạng thái và ngữ cảnh.** Mỗi thao tác dài trả job, có server đích, bước hiện tại, lỗi và kết quả; drawer hoạt động khi chuyển trang. Lock lifecycle ngăn backup/update/start xung đột. Retry chỉ khi có thể xác định thao tác chưa tạo bản trùng.
3. **Console và cấu hình phục vụ công việc thật.** Search/pause/copy log, lệnh mẫu/history, grouped properties, field lỗi cụ thể, nhãn restart. Giữ command vào BDS tách khỏi shell host.
4. **Backup trước rủi ro và retention.** Giữ stop/wait/archive/resume đang có; retention chỉ xóa snapshot sau khi snapshot mới đã thành công. Local backup vẫn cùng failure domain với server nên remote backup còn là khoảng trống.
5. **Health checks có căn cứ.** Check Ubuntu/architecture/dependencies/writable data/disk/process/network configuration, có lý do và bước xử lý. Một port bind được trên host không chứng minh người chơi Internet vào được qua NAT/firewall.
6. **UX cho desktop và mobile.** Glass dành cho navigation; content đọc rõ. Context server luôn xuất hiện trên controls power/file/config. Hỗ trợ bàn phím, zoom và giảm hiệu ứng như [DESIGN.md](DESIGN.md).

## File manager 0.4.0 và delta 0.4.1

Đối chiếu file workflow ngày **14/10/2026 tại Bangkok**. [Pterodactyl v1.15.1 tagged routes](https://github.com/pterodactyl/panel/blob/v1.15.1/routes/api-client.php) có rename/copy/write/compress/decompress/delete/create-folder cùng chmod và pull. [Crafty File Manager](https://docs.craftycontrol.com/pages/user-guide/file-manager/) hướng dẫn saved/dirty, Ctrl+S, context menu và upload nhắm thư mục. [AMP 2.7.2 release thread](https://discourse.cubecoders.com/t/amp-deimos-2-7-0-release-notes/38578) mô tả folder ZIP download, folder drag/drop, nhớ vị trí và trạng thái thao tác. Đây là các nguồn để chọn luồng cụ thể, không phải xác nhận Vortex có cùng mọi tính năng.

Vortex 0.4.0 đã nối scoped copy/move vùng chọn, rename, tạo file, ZIP mới/extract folder mới và editor revision. UI thêm current-folder search/sort, visible select-all/hidden-selection count, clipboard cùng server, picker thư mục, menu theo capabilities, upload nhiều file tuần tự và persistent editor Ctrl/Cmd+S. Managed editor nhận lại nội dung thực đã chuẩn hóa để trạng thái đã lưu khớp filesystem. Filesystem stage/activation/audit có rollback; ZIP có CRC32/type/prefix/path checks, giữ empty directories và tính cả implicit parents vào quota. Review độc lập đã chạy 6/6 archive và 10/10 file/HTTP tests; full-suite/browser cuối được ghi riêng trong VERIFICATION.

Đợt 0.4.1 đã kiểm tra file tools và giới hạn trên bản sao Ubuntu thật, sửa chỉ mục guard để tránh quét lặp runtime path và bổ sung bảng 100 hàng/trang. API vẫn trả full metadata, selection tối đa 1.000 nguồn; paging không biến request thư mục thành server-side pagination. Cancel/Keep Draft không submit biểu mẫu; cảnh báo cleanup đã commit được tách khỏi lỗi request. Số đo guard cục bộ và HTTP VPS được ghi riêng tại [VPS-ACCEPTANCE](VPS-ACCEPTANCE.md), không gộp thành một benchmark hoặc suy rộng sang độ trễ mọi host.

Giới hạn còn lại: stopped state cho mutation, chỉ ZIP, destination không merge/overwrite, 2 GiB/50.000 mục và 1.000 nguồn; mỗi upload 100 MiB, editor UTF-8 2 MiB. Không có SFTP, chmod/remote pull, folder upload trực tiếp, copy giữa instance, Monaco hay bulk delete. ZIP download cần tạo archive trước; demo ZIP là mô phỏng không tải được. Rollback không thay journal sau mất điện hoặc lock với mọi công cụ host. Các khả năng này không được dùng để khẳng định vượt đối thủ hoặc cô lập hosting nhiều tenant.
