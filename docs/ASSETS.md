# Vortex MC artwork

`public/assets/vortex-world.webp` delivers the original generated voxel landscape artwork for the Vortex MC interface. It is not an official Mojang or Apple asset. Created with the built-in ImageGen tool on 2026-10-12, then copied into the project so the interface can run without an external image service.

Release 0.5.1 encodes the same 2172 × 724 artwork as WebP, without changing its design. Delivery is 312,138 bytes instead of the 2,626,318-byte PNG master (about 88.1% fewer bytes). The original PNG is preserved in the private workspace backup under `output/pre-ui-polish/vortex-world.png.bk`; it is no longer requested by the interface or included in the public release. The WebP SHA-256 is `38b991ecc1950e6d675824e4acc6e264ffc6bd9eed04b1aa1341663bd1ddbf76`.

Generation prompt: Wide original panoramic voxel world for an iOS-style Minecraft Bedrock dashboard; floating lush grassy terraces, turquoise river and stepped waterfall, cubic trees, snowy block mountains, a subtle violet portal on the right, pastel lilac sunrise and atmospheric mist. Keep the left area calmer for a UI overlay. Crisp block geometry, cinematic depth, emerald/aqua/indigo palette. Landscape artwork only, no text, UI, logo, watermark, or characters.
